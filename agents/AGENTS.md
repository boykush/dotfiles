# グローバル設定

Claude Code / Codex 共通の個人ルール（`~/.claude/CLAUDE.md` と `~/.codex/AGENTS.md` の実体。dotfiles で管理）。

## 私のナレッジ（Scraps wiki）を引く

`scraps` MCP サーバーは私が書き溜めた個人 wiki（`boykush/wiki`）で、私の1次ソース。**wiki は私が持つ知識の語彙**。ある語は私が把握済み、無い語はまだ書いていないだけで、技術用語をどの高さから話すかの判断に使う。ただしあなたの思考を縛る境界ではなく、無い語を避ける理由にはならない。

**明示的に探すとき** —「こういうことが書いてある記事なかったっけ」「あれ何だっけ」と私が心当たりで聞くケース。題名を覚えていないので言い回しは曖昧になる。`search_scraps` を語を変えて何度か試す（`logic: "or"` で広げてから絞る）。無ければ「wiki にない」と明示する。

**よしなに引くとき** — 頼まれなくても、私が書いていそうな話題・私の文脈に閉じた語（プロジェクト名・略語・個人的な命名・過去の決定）・説明を足すか迷う技術用語が出たら、断りなく引いてから話す。空振りは黙って流す。毎回「wiki に無い」と報告されると会話が途切れる。

- `search_scraps` → 当たりを `get_scrap` で読む → 関連を辿るなら `lookup_scrap_links` / `lookup_scrap_backlinks`。語彙の地図が要るときは `list_tags`、タグ起点で並べるなら `lookup_tag_backlinks`。
- ある語は共通語彙として素で使い、定義から説明し直さない（`[[Title]]`、ctx 付きなら `[[Ctx/Title]]` を添えて私の理解と揃える）。無い語は弱い証拠。講義を始めず私の反応で上書きする。
- wiki は私の理解のスナップショットで、リポジトリの現状ではない。食い違ったらコードを正とし、その旨を報告する。
- MCP はクラスタ上の remote サーバーを見ている。繋がっていないセッションでは公開サイト <https://boykush.github.io/wiki/> を読む。ローカルに wiki の複製は置かないので、Grep / Read での代用はできない。

## 事実の置き場

AI に記録を任せると文書は増える一方で、**同じ事実が2箇所に書かれた瞬間から片方が古びる**。どう書くかより先に、置き場を1つに決める。

- **すでにどこかに書かれている事実を、散文に写さない**。写す代わりに、それを持つファイルを指す。写した時点で、以後ずっと2箇所を直す約束をしたことになる。
- **事実の持ち主は、それが間違っていると壊れる場所**。設定の制約はその設定ファイルのコメント、CI の認証はその workflow のコメント、値の一覧はそれを定義している宣言。文書はそこを指すだけにする。
- **一覧・表・件数を散文に持たない**（「対象は A・B・C の3つ」）。増減するものは、増減を決めているもの（変数・検索条件・discovery のクエリ）を指す。列挙は、片方だけ増やしたときに必ずずれる。
- **リポジトリをまたぐ事実を、片方の散文に置かない**。両方の当事者が必ず読むもの（双方のコメント、契約そのもの）に置く。互いに「相手が持っている」と書くと、実際にはどちらも持っていない状態になる。
- **AGENTS.md に書くのは、どれか1つのファイルには収まらないものだけ**——横断する禁止、踏んだ失敗、他リポジトリとの契約。手順と構成値は README、個々のファイルの理由はそのファイルのコメント。
- **禁止と落とし穴は AGENTS.md に置く**。毎セッションに届くのはここだけで、MCP や外部の文書は訊かれない限り読まれない。「これをすると壊れる」は訊かれる前に届いていなければ意味がない。
- 散文を消すときは、その事実が他のどこにあるかを確かめる。無ければ持ち主のところに1行で足してから消す。

## コードコメント

- 連続する1つのコメントブロックは**最大5行**。コード・設定ファイル・スクリプトを問わず一律で適用する。
- 5行に収まらないなら、コメントを削るかコード側を分かりやすくする。長い背景説明は README / ADR / PR 本文に書く。
- 「何をしているか」ではなく「なぜそうしたか」だけ書く。コードを読めば分かることは書かない。
- 差分の説明（`// 〜を追加`、`// 修正: 〜`）は書かない。それは commit message と PR の仕事。
- 既存のコメントは、その箇所自体を編集するとき以外は短縮しない。
